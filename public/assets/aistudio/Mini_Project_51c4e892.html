Minor Project Proposal

Web Development

Campus Event & Club Management System

1. Introduction

The Campus Event & Club Management System is a web-based application designed to provide a centralized platform for managing college events and student clubs.

The main purpose of the system is to make it easier for students and faculty members to access information about campus events, participate in activities, and manage event-related information from a single platform.

2. Problem Statement

In colleges, information about events, workshops, competitions, club activities, and other programs may be shared through different channels such as notices, messaging groups, or other platforms. This can make it difficult for students to keep track of upcoming activities and registrations.

The proposed system will provide a single platform where event and club-related information can be organized and accessed easily.

3. Users of the System

The system will have three types of users:

3.1 Student

Students will be able to:

  • Register and login
  • View upcoming events
  • Search and filter events
  • View event details
  • Register for events
  • View their registered events
  • Explore different college clubs
  • Provide feedback for events

3.2 Faculty

Faculty members will be able to:

  • Register/login to the system
  • View campus events and clubs
  • Create and manage events
  • View students registered for their events
  • Monitor event participation
  • View feedback related to their events

3.3 Admin

The administrator will manage the overall system and will be able to:

  • Manage students and faculty
  • Manage events
  • Manage clubs
  • View registrations
  • Manage system information
  • View overall participation and feedback

4. Main Modules

The proposed system will contain the following modules:

  1. User Registration and Login
  2. Student Module
  3. Faculty Module
  4. Admin Module
  5. Event Management
  6. Club Management
  7. Event Registration
  8. Feedback Management
  9. Database Management

5. Proposed Technologies

  • Frontend: HTML5, CSS3, JavaScript
  • Dynamic Data: AJAX / JSON / API
  • Backend: Node.js with Express
  • Database: MySQL
  • Authentication: Login, sessions and role-based access
  • Version Control: Git and GitHub

6. Expected Outcome

The final application will provide a centralized and user-friendly platform for managing college events and clubs.

Students will be able to discover and participate in campus activities, faculty members will be able to organize and monitor events, and administrators will be able to manage the overall system.

The project will also demonstrate concepts such as responsive web design, JavaScript, database connectivity, CRUD operations, authentication, API/AJAX-based data handling, testing, and deployment.

7. Scope for Future Enhancement

In the future, the system can be extended with features such as:

  • Event notifications
  • Email notifications
  • QR-based event attendance
  • Event certificates
  • Advanced participation reports
  • Mobile application integration
