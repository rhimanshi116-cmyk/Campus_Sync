#  CampusSync – Campus & Club Event Management System

CampusSync is a campus event and club management platform designed to bring college events, student activities, and clubs together in one place. It aims to simplify event discovery, participation, and campus engagement through a centralized digital platform.

##  Live Demo

🔗 [CampusSync – Live Website](https://campus-sync-green.vercel.app/)

##  About the Project

CampusSync provides a convenient platform for students, faculty, and administrators to manage and explore campus activities.

The project focuses on improving communication, event accessibility, and student participation by making campus events and club activities easier to discover and manage.

##  Features

-  Campus event discovery and management
-  College club management
-  Student-oriented event participation
-  Faculty event management
-  Administrative management
-  User authentication
-  User-friendly interface
-  Online deployment

##  User Roles

| Role | Responsibilities |
|---|---|
| Student | Explore events, discover clubs, and participate in campus activities |
| Faculty | Organize and manage campus events |
| Admin | Manage platform activities and users |
